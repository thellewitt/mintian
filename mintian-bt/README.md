# Mintian Broadcom Bluetooth ACL Priority Daemon

A lightweight, event-driven systemd daemon designed to address Bluetooth audio stuttering associated with connection-priority handling on Broadcom Bluetooth controllers in Linux.

`mintian-bt` applies Broadcom's vendor-specific `0xFC57` **Write High Priority Connection** HCI command directly to active ACL connections. The fix operates at the Bluetooth controller level and does not modify PipeWire, WirePlumber, ALSA, Bluetooth codecs, latency settings, or audio profiles.

On affected hardware, applying FC57 to the active ACL connection can improve connection scheduling consistency and eliminate Bluetooth audio stuttering.

## 1. How the Fix Works

`mintian-bt` integrates with the Linux Bluetooth stack at several layers:

* **Bluetooth Management Interface** identifies the Bluetooth controller manufacturer.
* **BlueZ D-Bus** connection events detect Bluetooth connections in real time.
* **`HCIGETCONNLIST`** retrieves active ACL connection handles directly from the Linux kernel.
* **sysfs device-tree traversal** resolves the underlying USB vendor:product ID.
* **Raw HCI** sends Broadcom's vendor-specific `0xFC57` command.

The FC57 packet used by the daemon is:

```text
01 57 FC 03 HH 00 01
```

`HH` contains the low byte of the active ACL connection handle selected by the daemon.

The daemon applies FC57 only when:

* A Broadcom controller is present.
* An active ACL connection exists.
* The kernel has established a valid ACL connection handle.

The design is event-driven and does not continuously poll for connection changes. The daemon also handles an already-active connection discovered when the service starts.

## 2. Test Your Hardware

Before installing the daemon, test the controller while your Bluetooth audio device is connected.

### Basic diagnostic test

Connect your Bluetooth headphones, speaker, or other device first.

Run:

```bash
sudo ./mintian-bt-test.py
```

The test checks for:

1. A Bluetooth HCI adapter.
2. A Broadcom Bluetooth controller.
3. An active ACL connection.

The controller manufacturer is identified through the Linux Bluetooth Management interface. The underlying USB vendor and product ID are resolved separately through the sysfs device tree.

The normal diagnostic test does **not** modify the Bluetooth connection.

### Live FC57 test

To apply the priority command to the currently active connection:

```bash
sudo ./mintian-bt-test.py --apply
```

The utility asks for confirmation before sending the command.

After FC57 is applied, play audio through the Bluetooth device and check whether the stuttering problem has been resolved.

If the live test eliminates the stuttering, the system is a strong candidate for the Mintian background daemon.

> The live test changes the current Bluetooth connection. The normal diagnostic test makes no changes.

## 3. Installation

The release archive contains:

```text
mintian-bt.py
mintian-bt.service
mintian-bt-test.py
mintian-bt-setup
mintian-bt-uninstall
README.md
```

### Extract the release archive

```bash
tar -xzf mintian-bt-1.0.0.tar.gz
```

Enter the release directory:

```bash
cd mintian-bt-1.0.0
```

Run the installer:

```bash
sudo ./mintian-bt-setup
```

The installer:

* Verifies that a Broadcom controller is present.
* Verifies that an active ACL connection exists.
* Performs the live FC57 test.
* Asks whether the daemon should be installed.
* Generates `/etc/mintian-bt.conf`.
* Installs the daemon and systemd service.
* Enables and starts the service.
* Verifies successful service activation.

Installed locations:

```text
/usr/local/sbin/mintian-bt.py
/etc/systemd/system/mintian-bt.service
/etc/mintian-bt.conf
```

The daemon source itself is not modified for individual systems.

---

## 4. After Installation

The daemon starts automatically at boot.

Check its status with:

```bash
systemctl status mintian-bt.service
```

View its log with:

```bash
journalctl -u mintian-bt.service
```

A typical connection event looks like:

```text
🎧 Connection event detected on D-Bus
⏳ Scheduled FC57 priority patch for hci0 handle=0x000C
🚀 Broadcom priority applied: hci0 handle=0x000C (12)
```

The daemon waits briefly after the D-Bus connection event so that the kernel has time to establish the ACL connection handle before FC57 is sent.

---

## 5. Configuration

The installer automatically creates:

```text
/etc/mintian-bt.conf
```

A typical configuration looks like:

```ini
# ------------------------------------------------------------
# Mintian Broadcom Bluetooth ACL Priority Daemon Configuration
# ------------------------------------------------------------
# This file was generated by mintian-bt-setup.
# Do not edit unless you know what you are doing.

HCI_DEV=0
USB_ID="05ac:828d"
```

`HCI_DEV` identifies the Bluetooth adapter used by the daemon.

`USB_ID` records the vendor:product ID of the underlying USB device when it can be determined by the installer.

Normally, there is no reason to edit this file manually.

## 6. Uninstallation

To remove the daemon and its systemd service:

```bash
sudo ./mintian-bt-uninstall
```

The uninstaller:

* Stops and disables the service.
* Removes the installed daemon and service files.
* Removes the configuration file when present.
* Reloads systemd.
* Verifies that the installation has been removed.

The uninstaller safely handles files that are already missing, allowing it to clean up a partial or previously removed installation.

## 8. Security and Reliability

`mintian-bt` runs as root because raw HCI access and the required kernel interface operations require elevated privileges.

The accompanying systemd service restricts the daemon with:

* `CAP_NET_ADMIN`
* `CAP_NET_RAW`
* `NoNewPrivileges=true`
* `PrivateDevices=true`
* `ProtectHome=true`
* `ProtectSystem=strict`
* `ProtectKernelTunables=true`
* `ProtectKernelModules=true`
* `ProtectControlGroups=true`
* `RestrictAddressFamilies=AF_UNIX AF_BLUETOOTH`
* Memory and task limits

The daemon also:

* Validates ACL handles.
* Distinguishes failed kernel connection queries from empty connection lists.
* Uses bounded raw-socket operations.
* Cancels pending connection workers during shutdown.

---

## 9. Scope

`mintian-bt` is intended for **Broadcom Bluetooth controllers**.

A Broadcom controller does not guarantee that the fix is required. The included test utility is intended to determine whether a Broadcom controller with an active ACL connection is suitable for testing the FC57 command.

Hardware support will continue to be verified as additional Broadcom controllers are tested.
